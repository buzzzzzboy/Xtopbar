# Xtopbar

把 macOS 的 App 切换变成 **Windows 任务栏**的手感：一条常驻的 App 条，点图标切换 / 最小化，悬停看窗口缩略图，⌘Tab 像 Alt+Tab 一样快按快放切回上一个；还可以停到屏幕底部当 Dock 用，加一个 Windows 风格的**开始菜单**，把常用 App **固定到任务栏 / 开始菜单**。

Fork 自 [lrylnx/TopTab](https://github.com/lrylnx/TopTab)（屏幕顶部的悬浮 App 切换条），在它的基础上改成了任务栏 / Dock 的替代品，并改名为 Xtopbar。

要求 macOS 14.0+（液态玻璃背景需要 macOS 26+，更早的系统自动换成毛玻璃）。

## 下载安装

到 [Releases](https://github.com/buzzzzzboy/Xtopbar/releases) 下载最新的 `Xtopbar-vX.Y.Z.zip`，解压后把 `Xtopbar.app` 拖进「应用程序」打开。之后的版本在软件里就能一键更新（见[更新](#更新)）。

第一次打开会请求两项权限：**屏幕录制**（窗口缩略图）和**辅助功能**（窗口列表、最小化、不挡窗口、⌘Tab 等）。建议都给，缺了哪项会怎样见[权限](#权限)。

> **从 TopTab 换过来**：bundle id 和签名证书都换了，第一次打开需要重新授予「屏幕录制」和「辅助功能」权限；原来的设置（固定项、隐藏的 App、各项开关）会自动搬过来。系统设置里旧的 TopTab 条目可以删掉。

## 和原版 TopTab 相比

默认外观仍是原版那条「图标 + 名称」的顶部切换条，差别在行为和新增的功能：

| | 原版 TopTab | Xtopbar |
|---|---|---|
| 条的位置 | 只能在屏幕顶部 | **顶部**（默认）/ **底部**（当 Dock 用）二选一 |
| 平时状态 | 藏起来，鼠标顶到屏幕顶部才唤出 | 默认**常驻**，窗口自动让位不被挡住（「不挡窗口」，全屏时自动让位）；关掉即回到原版的藏起来 + 顶边唤出 |
| 点前台 App | 无变化 | 把它的窗口**全部最小化**，再点一次恢复（Windows 任务栏同款，可关） |
| 显示哪些 App | 所有运行中的 App | 默认**只显示有窗口的 App**；另外可以**固定到任务栏**，没运行也留在条上 |
| 开始菜单 | 无 | 可选的 **⊞ 开始按钮**：搜索、已固定、最近使用、所有应用（可排序） |
| 图标样式 | 图标 + 名称 | 另可选**只显示图标**（Dock 风格大图标 + 运行指示点） |
| 系统 Dock | 不处理 | 可一键**隐藏系统 Dock**，关掉即还原 |
| 调度中心 | 条会挡在上面 | 打开调度中心 / App Exposé 时条**自动淡出**，退出后恢复 |
| App 名称 | 随 Xtopbar 自身语言（常显示英文名） | **跟随 macOS 系统语言**（系统是中文就显示「访达」「日历」「系统设置」） |

原版就有的功能（窗口缩略图预览、⌘Tab 呼出、右键隐藏 / 退出、界面缩放、背景材质、多屏唤出位置、开机自启、在线更新）全部保留。

## 功能

### 任务栏 / Dock

| 功能 | 说明 |
|---|---|
| **停靠位置** | 顶部（默认）/ 底部。底部时窗口预览与开始菜单向上弹，鼠标顶到屏幕底边（沿整条的宽度都行）唤出；顶部时向下弹，鼠标顶到屏幕顶部中央唤出 |
| **不挡窗口** | 默认开：条常驻不隐藏，压到条上的窗口自动挪开 / 缩短，窗口底部（停在顶部时是顶部）不再被盖住；有 App 全屏时条自动让位，顶到屏幕边缘仍可临时唤出。关掉后条平时藏起来，鼠标离开 0.2 秒自动隐藏（0.2 / 0.4 / 0.8 / 1.5 / 3 / 4 秒或常驻可调）。需要辅助功能权限 |
| **单击切换 / 最小化** | 点图标即切换，等价于点 Dock 图标。点**正在前台**的 App 把它的窗口全部最小化，再点一次恢复（可关）；窗口全被最小化的 App 点一下也会把窗口放回来 |
| **固定到任务栏** | 右键 App →「固定」→「固定到任务栏」：没在运行也留在条上（没有运行小圆点），点一下就打开；固定项排在最前，可「向左移 / 向右移」调整顺序 |
| **只显示有窗口的 App** | 默认开：运行中但一个窗口都没有的 App（关完窗口还挂着的 Safari、访达…）不上条，关掉最后一个窗口约 2 秒后消失；最小化的窗口也算有窗口；固定到任务栏的 App 始终显示。需要辅助功能权限，没有时不过滤 |
| **只显示图标** | Dock 风格：大图标 + 运行指示小圆点，名字悬停显示；默认是「图标 + 名称」标签 |
| **隐藏系统 Dock** | 把系统 Dock 设为自动隐藏 + 超长唤出延迟，让 Xtopbar 接替它（会重启一次 Dock）；关掉即还原你原来的设置 |
| **调度中心让位** | 打开调度中心（Mission Control）/ App Exposé 时条连同预览、开始菜单自动淡出，退出后恢复（自动隐藏模式则保持藏着）。需要辅助功能权限 |

### 开始菜单

设置里打开「显示开始按钮」后，条最左边出现 **⊞** 按钮（也可以从菜单栏图标 →「开始菜单」打开）。

| 区域 | 说明 |
|---|---|
| **搜索框** | 打开即可打字搜索已安装的 App（按名称，也能匹配 bundle id），↑↓ 选、回车打开 |
| **已固定** | 固定到开始菜单的 App 网格，和任务栏的固定项各管各的（同 Windows） |
| **最近使用** | 最近打开过的 8 个 App |
| **所有应用 ›** | 全部已安装的 App，含访达、Safari 和套在别的 App 包里的独立 App；可按 **名称 A–Z**（按首字母分组，中文名按拼音首字母归组）/ **最近加入** / **最近更新** 排序，后两种按今天、昨天、最近 7 天、最近 30 天、今年、更早分组并标出日期 |
| **底部** | 当前用户名和 Xtopbar 设置入口 |

开始菜单里右键 App：打开、固定到开始菜单 / 任务栏（或取消固定）、在访达中显示。Esc、点菜单外面、打开一个 App 都会收起菜单。

### 切换与预览（原版功能）

| 功能 | 说明 |
|---|---|
| **窗口预览** | 悬停有 2 个以上窗口（或有被最小化的窗口）的 App，弹出各窗口缩略图：点哪张切哪个窗口，被最小化的点一下就恢复；点左上角 × 直接关掉那个窗口，不碰这个 App 的其它窗口 |
| **⌘Tab 呼出** | 设置里开启后接管系统 ⌘Tab：在**鼠标位置**弹出条并预选上一个 App —— 快按快放 = 立刻切回上一个（Windows Alt+Tab）；按住 ⌘ 继续按 Tab，高亮沿图标从左到右走、到头绕回，也可以直接用鼠标点选；松开 ⌘ 确认后条立刻消失，Esc 取消。需要辅助功能权限 |
| **右键隐藏 / 退出** | 右键 App →「隐藏此 App」（不占条上的位置，但 App 照常在后台运行；在设置 →「已隐藏的 App」里放回）/「退出 App」 |
| **多屏唤出位置** | 接外接屏时，顶边 / 底边唤出只认一块屏：**系统主显示器**（默认，带菜单栏那块）/ 内置屏（刘海那块）/ 鼠标所在屏。⌘Tab 不受影响，始终在鼠标位置弹出 |
| **唤出区宽度** | 停在顶部时，屏幕顶部中央多宽的范围能唤出：60–400 pt，默认 120 pt ≈ 4 个状态栏图标；外接屏误触频繁就调小，难唤出就调大 |
| **界面缩放** | 80%–130%，拖动即时生效，条与窗口预览等比缩放、点击区域同步 |
| **背景材质** | 液态玻璃（默认，macOS 26+，跟随浅色 / 深色与「降低透明度」等辅助功能开关）/ 毛玻璃 / 纯色；待机不透明度与进出场动画可调 |
| **开机自启** | 设置里一键开启 |
| **在线更新** | 启动后自动检查新版本，有就弹窗一键更新 |

## 操作速查

| 操作 | 结果 |
|---|---|
| 单击 App 图标 | 切到前台；如果它已经在前台，最小化它的全部窗口（再点恢复） |
| 单击**没有小圆点**的图标 | 固定但没在运行的 App —— 打开它 |
| 悬停 App 图标 0.12 秒 | 弹出该 App 的窗口缩略图（仅当有 ≥2 个窗口或有被最小化的窗口） |
| 单击缩略图 / 缩略图左上角 × | 切到那个窗口（最小化的先恢复）/ 关掉那个窗口 |
| **App 上右键** | 隐藏此 App（未固定时）、退出 App；「固定」子菜单：固定到任务栏 / 取消固定、向左移 / 向右移、固定到开始菜单 / 取消固定 |
| 条的空白处右键 | 设置、打开开始菜单、自动隐藏、预览开关、权限、刷新列表、退出 |
| 单击 **⊞ 开始按钮** | 打开 / 关闭开始菜单 |
| 鼠标顶到屏幕底边 / 顶部中央 | 条藏起来时（关了「不挡窗口」或有 App 全屏）唤出条 |
| **⌘Tab**（设置里开启） | 快按快放切回上一个 App；按住 ⌘ 连按 Tab 逐个选，松开确认，Esc 取消 |
| 菜单栏图标 | 显示 / 隐藏悬浮条、开始菜单、设置、检查更新、自动隐藏、预览、权限、退出 |

## 设置

菜单栏图标 →「设置…」，或条上右键 →「设置…」。改动**即时生效**，不用重启。

| 分组 | 项 |
|---|---|
| 通用 | 开机自动启动、在菜单栏显示图标 |
| Dock 与开始菜单 | Dock 位置（顶部 / 底部）、显示开始按钮、只显示图标、只显示有窗口的 App、隐藏系统 Dock、不挡窗口、点击前台 App 最小化窗口、固定到任务栏 / 开始菜单的列表（调整顺序、移除） |
| 悬浮条 | 启用悬浮条、唤醒热区宽度、唤出所在屏幕、窗口预览、只显示已打开的窗口、自动隐藏时长、⌘Tab 呼出、已隐藏的 App、背景材质、界面缩放、待机不透明度、进出场动画 |
| 权限 | 屏幕录制 / 辅助功能的实时状态与授权按钮 |
| 关于 | 版本、检查更新、启动后自动检查更新 |

隐藏了菜单栏图标，也还能右键悬浮条 →「设置…」回到设置窗口。

## 权限

| 权限 | 用途 | 没有时的降级 |
|---|---|---|
| 屏幕录制 | 抓窗口缩略图、读取窗口标题 | 预览卡片只显示 App 图标 |
| 辅助功能 | 列出窗口（含最小化窗口）、聚焦 / 最小化指定窗口、不挡窗口、只显示有窗口的 App、调度中心让位、⌘Tab | 看不到最小化窗口，点缩略图退化成把整个 App 拉到前台；上面这些依赖它的功能不生效 |

首次启动会主动弹一次系统授权请求，授权一次长期有效。权限状态在 **设置 → 权限** 里实时显示，「授权」按钮会弹系统请求并跳到对应的设置面板。改动系统权限后需重启 Xtopbar 生效。

## 更新

启动 3 秒后自动检查一次新版本（每小时最多一次），没有新版本就毫无动静。有新版本会弹窗：

| 按钮 | 行为 |
|---|---|
| 立即更新 | 自动下载 → 校验签名 → 退出并替换 → 重新打开 |
| 稍后 | 这次不更新，下次启动再提示 |
| 跳过这个版本 | 静默检查不再为这个版本提示；手动「检查更新…」仍会提示 |

手动检查：菜单栏图标 →「检查更新…」，或 **设置 → 关于**。也可以在设置里关掉自动检查。

> 更新后如果提示需要重新授予屏幕录制 / 辅助功能权限，说明新版本换了签名证书，重新授权一次即可。

## 构建

需要 Xcode 命令行工具。

```bash
./build.sh          # 生成图标 + 双架构（arm64 / x86_64）编译 + 自签名 + 校验
open Xtopbar.app
```

发版（打包并上传到 GitHub Releases，供在线更新使用，不需要任何服务器）：

```bash
GITHUB_TOKEN=<token> ./scripts/make-release.sh 2.1.1 "更新说明"
```

详细流程见 [docs/RELEASING.md](docs/RELEASING.md)；窗口枚举、AX 的坑、不挡窗口的几何、自签名证书、动效参数等实现细节见 [docs/INTERNALS.md](docs/INTERNALS.md)。
