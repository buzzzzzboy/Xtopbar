# Xtopbar

把 macOS 的 App 切換變成 **Windows 工作列**的手感：一條常駐的 App 條，點圖示切換 / 最小化，懸停看視窗縮圖，⌥Tab 在螢幕中央鋪開所有視窗的縮圖挑一個切過去；還可以停到螢幕底部當 Dock 用，加一個 Windows 風格的**開始選單**，把常用 App **固定到工作列 / 開始選單**。

Fork 自 [lrylnx/TopTab](https://github.com/lrylnx/TopTab)（螢幕頂部的懸浮 App 切換條），在它的基礎上改成了工作列 / Dock 的替代品，並改名為 Xtopbar。

要求 macOS 14.0+（液態玻璃背景需要 macOS 26+，更早的系統自動換成毛玻璃）。

## 下載安裝

到 [Releases](https://github.com/buzzzzzboy/Xtopbar/releases) 下載最新的 `Xtopbar-vX.Y.Z.zip`，解壓縮後把 `Xtopbar.app` 拖進「應用程式」開啟。之後的版本在軟體裡就能一鍵更新（見[更新](#更新)）。

第一次開啟會請求兩項權限：**螢幕錄製**（視窗縮圖）和**輔助使用**（視窗列表、最小化、不擋視窗、⌥Tab 等）。建議都給，缺了哪項會怎樣見[權限](#權限)。

> **從 TopTab 換過來**：bundle id 和簽名憑證都換了，第一次開啟需要重新授予「螢幕錄製」和「輔助使用」權限；原來的設定（固定項、隱藏的 App、各項開關）會自動搬過來。系統設定裡舊的 TopTab 項目可以刪掉。

## 和原版 TopTab 相比

預設外觀仍是原版那條「圖示 + 名稱」的頂部切換條，差別在行為和新增的功能：

| | 原版 TopTab | Xtopbar |
|---|---|---|
| 條的位置 | 只能在螢幕頂部 | **頂部**（預設）/ **底部**（當 Dock 用）二選一 |
| 多螢幕 | 只在一塊螢幕上 | 預設**每塊螢幕各一條**，每條只放視窗在那塊螢幕上的 App（同 Windows 多工作列） |
| 平時狀態 | 藏起來，滑鼠頂到螢幕頂部才喚出 | 預設**常駐**，視窗自動讓位不被擋住（「不擋視窗」，全螢幕時自動讓位）；關掉即回到原版的藏起來 + 頂邊喚出 |
| 點前景 App | 無變化 | 把它的視窗**全部最小化**，再點一次恢復（Windows 工作列同款，可關） |
| 顯示哪些 App | 所有執行中的 App | 預設**只顯示有視窗的 App**；另外可以**固定到工作列**，沒執行也留在條上 |
| 開始選單 | 無 | 可選的 **⊞ 開始按鈕**：搜尋、已固定、最近使用、所有應用（可排序） |
| 圖示樣式 | 圖示 + 名稱 | 另可選**只顯示圖示**（Dock 風格大圖示 + 執行指示點） |
| 系統 Dock | 不處理 | 可一鍵**隱藏系統 Dock**，關掉即還原 |
| 指揮中心 | 條會擋在上面 | 開啟指揮中心 / App Exposé 時條**自動淡出**，退出後恢復 |
| App 名稱 | 隨 Xtopbar 自身語言（常顯示英文名） | **跟隨 macOS 系統語言**（系統是中文就顯示「Finder」「行事曆」「系統設定」） |

原版就有的功能（視窗縮圖預覽、右鍵隱藏 / 結束、介面縮放、背景材質、多螢幕喚出位置、開機自啟、線上更新）全部保留。

> **從 v2.6.0 升級**：「⌘Tab 叫出」已移除，系統 ⌘Tab 不再被攔截、恢復原生的 App 切換器；要挑視窗請用 ⌥Tab 視窗切換器。

## 功能

### 工作列 / Dock

| 功能 | 說明 |
|---|---|
| **停靠位置** | 頂部（預設）/ 底部。底部時視窗預覽與開始選單向上彈，滑鼠頂到螢幕底邊（沿整條的寬度都行）喚出；頂部時向下彈，滑鼠頂到螢幕頂部中央喚出 |
| **不擋視窗** | 預設開：條常駐不隱藏，壓到條上的視窗自動挪開 / 縮短，視窗底部（停在頂部時是頂部）不再被蓋住；有 App 全螢幕時條自動讓位，頂到螢幕邊緣仍可臨時喚出。關掉後條平時藏起來，滑鼠離開 0.2 秒自動隱藏（0.2 / 0.4 / 0.8 / 1.5 / 3 / 4 秒或常駐可調）。需要輔助使用權限 |
| **單擊切換 / 最小化** | 點圖示（放開滑鼠時）即切換，等價於點 Dock 圖示。點**正在前景**的 App 把它的視窗全部最小化，再點一次恢復（可關）；視窗全被最小化的 App 點一下也會把視窗放回來 |
| **固定到工作列** | 右鍵 App →「固定」→「固定到工作列」：沒在執行也留在條上（沒有執行小圓點），點一下就開啟；固定項排在最前，可「向左移 / 向右移」調整順序 |
| **拖曳排序** | 按住標籤左右拖，放開就換位置（同 Windows 工作列）；固定項和執行中的 App 各自在組內排。固定項的順序永久記住；執行中 App 排好的順序在它結束前都保留，結束後再開會回到最右邊 |
| **只顯示有視窗的 App** | 預設開：執行中但一個視窗都沒有的 App（關完視窗還掛著的 Safari、Finder…）不上條，關掉最後一個視窗約 2 秒後消失；最小化的視窗也算有視窗；固定到工作列的 App 始終顯示。需要輔助使用權限，沒有時不過濾 |
| **視窗數圓圈** | App 在這塊螢幕上開著 2 扇以上視窗（含最小化的）時，圖示右上角出現數字小圓圈，多於 9 扇寫 9+；懸停提示也會寫「N 個視窗」。開「在所有螢幕上顯示」時數的是那條所在螢幕上的視窗，單條模式數全部。需要輔助使用權限 |
| **只顯示圖示** | Dock 風格：大圖示 + 執行指示小圓點，名字懸停顯示；預設是「圖示 + 名稱」標籤 |
| **隱藏系統 Dock** | 把系統 Dock 設為自動隱藏 + 超長喚出延遲，讓 Xtopbar 接替它（會重啟一次 Dock）；關掉即還原你原來的設定 |
| **在所有螢幕上顯示** | 預設開：接外接螢幕時每塊螢幕各一條。每條只放**視窗在那塊螢幕上**的 App（視窗跨兩塊螢幕算重疊多的那塊；一個 App 在兩塊螢幕都有視窗就兩條都有，名稱後面帶上那塊螢幕上視窗目前的分頁 / 標題，例如「Google Chrome (YouTube)」，過長截斷），固定項每條都有；視窗拖到別的螢幕約 1 秒內跟著換條。點副螢幕條上的 App 切到 / 收起的是那塊螢幕上的視窗，懸停預覽也只列那塊螢幕的視窗；開始選單從哪條點就在哪塊螢幕彈出；不擋視窗、全螢幕讓位、頂邊 / 底邊喚出各螢幕各管各的。按螢幕分 App 需要輔助使用權限，沒有時每條都顯示全部。關掉則只在一塊螢幕上顯示（見「多螢幕喚出位置」） |
| **指揮中心讓位** | 開啟指揮中心（Mission Control）/ App Exposé 時條連同預覽、開始選單自動淡出，退出後恢復（自動隱藏模式則保持藏著） |

### 開始選單

設定裡開啟「顯示開始按鈕」後，條最左邊出現 **⊞** 按鈕（也可以從選單列圖示 →「開始選單」開啟）。

| 區域 | 說明 |
|---|---|
| **搜尋框** | 開啟即可打字搜尋已安裝的 App（按名稱，也能匹配 bundle id），↑↓ 選、Return 開啟 |
| **已固定** | 固定到開始選單的 App 網格，和工作列的固定項各管各的（同 Windows） |
| **最近使用** | 最近開啟過的 8 個 App |
| **所有應用 ›** | 全部已安裝的 App，含 Finder、Safari 和套在別的 App 包裡的獨立 App；可按 **名稱 A–Z**（按首字母分組，中文名按拼音首字母歸組）/ **最近加入** / **最近更新** 排序，後兩種按今天、昨天、最近 7 天、最近 30 天、今年、更早分組並標出日期 |
| **底部** | 目前使用者名稱和 Xtopbar 設定入口 |

開始選單裡右鍵 App：開啟、開啟設定檔（Chromium 系瀏覽器）、固定到開始選單 / 工作列（或取消固定）、在 Finder 中顯示。Esc、點選單外面、開啟一個 App 都會收起選單。

### 視窗切換器（⌥Tab）

類似 [DockDoor](https://github.com/ejbills/DockDoor) 的視窗切換器、Windows 的 Alt+Tab：按一下就看到**目前桌面所有視窗（含最小化的）**的縮圖，不分 App。預設開啟，可在設定 →「視窗切換器」關掉；和懸浮條互不依賴，條關著也能用。

| 操作 | 結果 |
|---|---|
| 按住 **⌥** 按 **Tab** | 螢幕中央（滑鼠所在螢幕）彈出格狀面板，每張卡片是一個視窗：上面 App 圖示 + 視窗標題，下面縮圖；預選**上一個**視窗 |
| 快按快放 ⌥Tab | 直接切回上一個視窗，面板不會閃出來 |
| 繼續按 Tab / ⇧Tab | 選取往後 / 往前走一格，到頭繞回；**⌥⇧Tab** 一開始就從最後一個往回選 |
| ← → / ↑ ↓ | 左右走一格 / 上下跳一行 |
| 滑鼠移到卡片上 / 點一下 | 選它 / 立刻切過去 |
| 鬆開 ⌥ / Return | 切到選取的視窗（最前面的視窗排第一，順序就是最近使用的順序）；選的是最小化視窗就先還原 |
| Esc | 取消 |

- 列**目前桌面看得到的視窗** + **所有最小化的視窗**（排在最後，卡片左下角標「已最小化」）；已隱藏（⌘H）的 App、其它桌面（Space）上的不列；多螢幕時所有螢幕上的視窗都會列出來
- 視窗多時自動換行、整塊等比縮小到放得下；最後一行不滿時置中
- 需要**輔助使用**權限（攔截 ⌥Tab、切到指定視窗）；縮圖與完整標題需要**螢幕錄製**，沒有時卡片顯示 App 圖示
- 開著時 ⌥Tab 在各 App 裡原本的作用（少數輸入框裡插入定位字元）會被接管，用不到就關掉

### 切換與預覽（原版功能）

| 功能 | 說明 |
|---|---|
| **視窗預覽** | 懸停有 2 個以上視窗（或有被最小化的視窗）的 App，彈出各視窗縮圖：點哪張切哪個視窗，被最小化的點一下就恢復；點左上角 × 直接關掉那個視窗，不碰這個 App 的其它視窗 |
| **右鍵隱藏 / 結束** | 右鍵 App →「隱藏此 App」（不佔條上的位置，但 App 照常在背景執行；在設定 →「已隱藏的 App」裡放回）/「結束 App」 |
| **多螢幕喚出位置** | 關掉「在所有螢幕上顯示」時才有：條只在一塊螢幕上，頂邊 / 底邊喚出只認這一塊：**系統主顯示器**（預設，帶選單列那塊）/ 內建螢幕（劉海那塊）/ 滑鼠所在螢幕 |
| **喚出區寬度** | 停在頂部時，螢幕頂部中央多寬的範圍能喚出：60–400 pt，預設 120 pt ≈ 4 個狀態列圖示；外接螢幕誤觸頻繁就調小，難喚出就調大 |
| **介面縮放** | 80%–130%，拖曳即時生效，條與視窗預覽等比縮放、點擊區域同步。也可以像原生 Dock 一樣按住開始按鈕旁的分隔線上下拖 |
| **圓角** | 懸浮條四角弧度 0–30 pt：0 是直角，拉到底是膠囊形 |
| **背景材質** | 液態玻璃（預設，macOS 26+，跟隨淺色 / 深色與「降低透明度」等輔助使用開關）/ 毛玻璃 / 純色；待機不透明度與進出場動畫可調 |
| **開機自啟** | 設定裡一鍵開啟 |
| **線上更新** | 啟動時及常駐期間每小時自動檢查 GitHub 新版本，有就彈窗一鍵更新 |

## 操作速查

| 操作 | 結果 |
|---|---|
| 單擊 App 圖示 | 切到前景；如果它已經在前景，最小化它的全部視窗（再點恢復） |
| 單擊**沒有小圓點**的圖示 | 固定但沒在執行的 App —— 開啟它 |
| 懸停 App 圖示 0.12 秒 | 彈出該 App 的視窗縮圖（僅當有 ≥2 個視窗或有被最小化的視窗） |
| 單擊縮圖 / 縮圖左上角 × | 切到那個視窗（最小化的先恢復）/ 關掉那個視窗 |
| **App 上右鍵** | 隱藏此 App（未固定時）、結束 App；Chrome / Edge / Brave / Vivaldi 等瀏覽器有 2 個以上設定檔時多一個「開啟設定檔」子選單，點一個就用它開新視窗（沒在執行也行；第一次會跳出「想取用其他 App 的資料」，要按允許才讀得到設定檔列表）；「固定」子選單：固定到工作列 / 取消固定、向左移 / 向右移、固定到開始選單 / 取消固定 |
| 條的空白處右鍵 | 設定、開啟開始選單、自動隱藏、預覽開關、權限、重新整理列表、結束 |
| 單擊 **⊞ 開始按鈕** | 開啟 / 關閉開始選單 |
| 滑鼠頂到螢幕底邊 / 頂部中央 | 條藏起來時（關了「不擋視窗」或有 App 全螢幕）喚出條 |
| **⌥Tab**（預設開啟） | 全視窗切換器：快按快放切回上一個視窗；按住 ⌥ 連按 Tab（⇧Tab 反向）/ 方向鍵 / 滑鼠挑，鬆開確認，Esc 取消 |
| 選單列圖示 | 顯示 / 隱藏懸浮條、開始選單、設定、檢查更新、自動隱藏、預覽、權限、結束 |

## 設定

選單列圖示 →「設定…」，或條上右鍵 →「設定…」。改動**即時生效**，不用重啟。

| 分組 | 項 |
|---|---|
| 一般 | 開機自動啟動、在選單列顯示圖示 |
| Dock 與開始選單 | Dock 位置（頂部 / 底部）、顯示開始按鈕、只顯示圖示、只顯示有視窗的 App、隱藏系統 Dock、不擋視窗、點擊前景 App 最小化視窗、固定到工作列 / 開始選單的列表（調整順序、移除） |
| 懸浮條 | 啟用懸浮條、喚醒熱區寬度、喚出所在螢幕、視窗預覽、只顯示已開啟的視窗、自動隱藏時長、已隱藏的 App、背景材質、介面縮放、圓角、待機不透明度、進出場動畫 |
| 視窗切換器 | ⌥Tab 視窗切換器開關 |
| 權限 | 螢幕錄製 / 輔助使用的即時狀態與授權按鈕 |
| 關於 | 版本、檢查更新、啟動後自動檢查更新 |

隱藏了選單列圖示，也還能右鍵懸浮條 →「設定…」回到設定視窗。

## 權限

| 權限 | 用途 | 沒有時的降級 |
|---|---|---|
| 螢幕錄製 | 抓視窗縮圖、讀取視窗標題 | 預覽卡片只顯示 App 圖示 |
| 輔助使用 | 列出視窗（含最小化視窗）、聚焦 / 最小化指定視窗、不擋視窗、只顯示有視窗的 App、指揮中心讓位、⌥Tab 視窗切換器 | 看不到最小化視窗，點縮圖退化成把整個 App 拉到前景；上面這些依賴它的功能不生效 |

首次啟動會主動彈一次系統授權請求，授權一次長期有效。權限狀態在 **設定 → 權限** 裡即時顯示，「授權」按鈕會彈系統請求並跳到對應的設定面板。改動系統權限後需重啟 Xtopbar 生效。

## 更新

啟動 3 秒後自動檢查一次新版本，之後只要 Xtopbar 開著就**每小時**再檢查一次，睡眠喚醒後也會補查一次 —— GitHub 上一發布新版，常駐中的 Xtopbar 最晚一小時內就會發現。沒有新版本就毫無動靜。有新版本會彈窗：

| 按鈕 | 行為 |
|---|---|
| 立即更新 | 自動下載 → 驗證簽名 → 退出並替換 → 重新開啟 |
| 稍後 | 這次不更新，之後不再彈窗打擾（選單列會一直顯示「有新版本 →」），下次啟動再提示 |
| 跳過這個版本 | 靜默檢查不再為這個版本提示；手動「檢查更新…」仍會提示 |

手動檢查：選單列圖示 →「檢查更新…」，或 **設定 → 關於**。也可以在設定裡關掉自動檢查。

> 更新後如果提示需要重新授予螢幕錄製 / 輔助使用權限，說明新版本換了簽名憑證，重新授權一次即可。

## 建置

需要 Xcode 命令列工具。

```bash
./build.sh          # 生成圖示 + 雙架構（arm64 / x86_64）編譯 + 自簽名 + 驗證
open Xtopbar.app
```

發版（打包並上傳到 GitHub Releases，供線上更新使用，不需要任何伺服器）：

